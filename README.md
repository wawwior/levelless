
## Levelless

"Removes" enchantment levels by making relevant code always return the max level for a given enchantment.

Since this was written for a modpack, this does not change any enchanting mechanics and is not balanced to use without additional mods.

Additionally, an affected ItemStack's NBT data remains completely unchanged, so it is safe to remove this mod.

Inspired by [Enchancement](https://modrinth.com/mod/enchancement).
